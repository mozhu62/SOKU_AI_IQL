# IQL N-step 回报

正式配置 `configs/iql_suika.yaml` 已设置 `iql.n_step: 8`。该项接受任意正整数；旧 YAML 缺字段时默认 1，保持单步行为。N 越大，训练序列、显存占用和计算量也会随之增加。

每个有效监督位置累计真实数据的 k 步奖励：

`target = r[t] + gamma*r[t+1] + ... + gamma^(k-1)*r[t+k-1] + gamma^k*V(s[t+k])`

k 不超过 N；连续片段结束时缩短。真实终局移除末项；截断但有真实后继时，仍从该后继的 V bootstrap。没有跨断帧、episode 或终局累计奖励。奖励和 gamma 数值不变，step 指数据的一个有效帧转移，不是一次完整出招或一次优化器更新。

Dataset 保留原 burn-in，加取 N 个尾部状态，生成累计奖励、实际步数、折扣、终局标志和 bootstrap 索引。Actor/Q/V 的当前监督只取前 L 个输出，V 后继按索引提取。TCN 是因果网络，尾部未来帧不进入当前动作预测。网络形状、推理窗口和动作空间不变，但训练前向序列变长，会增加开销。

Q 使用 N-step 目标替换单步目标，不额外叠加第二个 TD loss；V expectile 和 Actor 优势加权逻辑不变。Neutral 类别权重仍为 0.25，保留全部有效帧。验证 TD 误差同步采用 N-step，NLL/Top-1 定义不变，best 仍按原 NLL 规则选择。

旧 IQL checkpoint 可续训。显式修改 N 时打印警告，保留权重与优化器，不声称精确复现旧训练。完整 checkpoint、配置导出会保留 N；实战 Actor 加载不受影响。日志新增 `n_step` 和 `n_step_actual_mean`，诊断页显示跨度。旧跨度与新跨度的 TD MSE/EV 不宜直接比较。

这不是保证更强的改动：多步奖励来自数据行为策略的后续动作，属于多步 IQL 变体；更大的 N 会增加行为策略影响、目标方差和计算开销。当前先用 8 步观察，不自动调整奖励或折扣。

已添加折扣、终局、截断、后继索引和 N=1 等价测试源码；本次未运行测试或编译。
