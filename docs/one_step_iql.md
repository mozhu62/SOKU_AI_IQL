# 恢复单步 IQL

正式训练与验证均使用 y=r+gamma*(1-terminal)*V(next_state)。数据只读取监督段外一个额外后继，不再构造多步奖励、折扣或bootstrap索引。iql.n_step固定为1，旧配置填30会明确报错。

保留历史 n_step_returns 辅助函数供旧测试/工具引用，但正式采样及损失不再调用。历史窗口与监督序列长度不变，奖励和gamma不变。

旧IQL checkpoint可使用明确设置n_step=1的配置恢复权重和优化器，运行时会提示TD跨度变化；这不是与旧训练完全等价的续训，旧TD统计不能直接比较。从BC重新初始化仍用--init-bc与新输出目录。

这里只恢复标准单步TD。项目原有Neutral类别降权、Actor预热等额外设置保持原样，不能据此称所有训练设置都已恢复论文原版。
