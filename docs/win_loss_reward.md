# 小局胜负奖励

正式配置新增 reward.win=10.0、reward.loss=10.0（均填非负系数，loss在计算时取负）。默认配置缺字段按0处理，保持旧训练兼容。

r = damage_dealt×对方扣血 - damage_taken×己方扣血 + win×胜利标记 - loss×失败标记。

NPZ没有可靠的完整两胜制胜者字段，因此这里是小局KO奖励，不是整场胜负。只在有效且terminated的转移上，前态双方HP>0、后态一方HP<=0且另一方仍>0时计一次。双倒、超时、截断、缺失KO后继等不推断胜负。不按剩余HP判断获胜，也不把终局奖励复制到整局每一帧。

TD跨度由`iql.n_step`决定，终局奖励可在同一个N-step目标内向前传播；终局不bootstrap。伤害奖励叠加不替换。增加奖励改变了目标尺度，10是初始可配置值，不保证最优。

修改奖励后建议从BC新建IQL训练目录。旧IQL续训如奖励不同会明确拒绝，不能静默修改目标；若需要原目标续训可将win/loss设0。无需重新采集或改写NPZ。本次未执行测试或训练。
