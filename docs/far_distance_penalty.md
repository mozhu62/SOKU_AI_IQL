# 远距离持续惩罚

远距离事件使用原始状态中的水平相对距离 `abs(relative_x)`。当距离严格大于 `reward.far_distance_threshold` 且该转移有效时，每个游戏帧持续扣除 `reward.far_distance_penalty`。不使用垂直距离，避免双方正常跳跃时因高度差受到误罚。

正式配置的阈值为 300，单帧惩罚为 0.001。距离恰好等于阈值时不惩罚。将惩罚设为 0 可以关闭奖励塑形，同时保留事件诊断。该值是固定单帧惩罚，不随超出阈值的距离继续放大，避免远距离状态产生过大的回报尖峰。

训练批次和健康报告记录 `far_distance_event`、`horizontal_distance`、`far_distance_penalty`，并汇总事件数量、占比及总惩罚。N-step 会按照正常折扣累计连续远距离惩罚。

该实现不修改模型输入、网络结构或实战推理。旧 IQL checkpoint 没有该字段时按关闭解释；启用非零惩罚会改变奖励目标，应从 BC 初始化新实验并使用独立输出目录。

已添加阈值、无效转移和距离绝对值测试源码；按项目要求未运行测试、编译或训练。
