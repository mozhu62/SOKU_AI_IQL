# 压制事件与奖励

压制事件定义为：同一条有效转移前后，对手至少一侧状态处于防御，并且对手当前灵力真实下降。事件归属到造成灵力下降的前一条转移，不跨断帧、episode 或终局边界。单纯举盾、灵力不变、只接近对手均不算压制。

正式配置使用 `reward.pressure: 0.05`，每条满足条件的转移增加一次固定奖励。灵力下降量只作为 `pressure_spirit_loss` 诊断数据记录，不直接乘进奖励，避免不同角色和招式的削灵量让奖励尺度失控。设为 0 可以关闭该奖励，同时保留事件诊断。

训练批次和健康报告分别记录 `pressure_event`、`pressure_spirit_loss`、`pressure_reward`。N-step 会按正常折扣累计压制奖励。该实现复用既有 `opponent_guarding` 和 `opponent_current_spirit`，不改变模型输入、网络结构或实战推理，旧 Actor 权重仍可加载。

旧 IQL checkpoint 的配置中不存在该字段时按 0 解释。若续训时把它改成非零值，现有恢复校验会拒绝静默改变奖励目标；应从 BC 初始化新实验，或明确沿用旧值 0。
